### What's new

- **Running without the Server Members intent.** A self-hosted CalCrony bot now starts even when its Discord application does not have the Server Members intent. Without it, `/availability role` and `/availability slots` for a role say they are off, and on the website an RSVP option or poll limited to a role asks you to choose from Discord, where your roles are checked as before. With the intent, nothing changes.

### How to use it

1. Self-hosting: leave `DISCORD_SERVER_MEMBERS_INTENT` unset, and the bot asks for the intent only when your application has it. Set it to `on` or `off` to choose yourself.
